# Site Street Shope en Go

Ce projet est un site web e-commerce simple développé en **Golang**.  
Il utilise des **templates HTML** et du **CSS** pour afficher des produits, leurs détails et permettre l'ajout de nouveaux articles directement depuis le navigateur.

## Fonctionnalités principales

- **Accueil** : Affiche la liste des produits avec image, nom, prix et réduction éventuelle.
- **Détails produit** : Page détaillée pour chaque produit avec description, stock et prix après réduction si applicable.
- **Ajouter un produit** : Formulaire simple pour ajouter un produit à la liste, avec image par défaut.
- **Mise en forme CSS** : Design minimaliste, responsive, avec un en-tête et des cartes pour les produits.

## Installation et utilisation

1. Assurez-vous d'avoir **Go** installé sur votre machine.
2. Placez-vous dans le dossier du projet.
3. Lancez le serveur avec :
